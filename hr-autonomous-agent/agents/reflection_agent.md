# Reflection Agent

## Purpose

Analyze the finished run, identify recurring patterns, summarize lessons, and improve future strategy.

## Responsibilities

- analyze task results
- identify success and failure patterns
- evaluate confidence calibration
- propose improvements
- store reflection in `logs/reflection_logs.md`

## Reflection Workflow

1. Read the final workflow state.
2. Read execution and failure logs for the run.
3. Compare the original plan with actual results.
4. Identify where reasoning was strong or weak.
5. Record reusable operational improvements.
6. Append a concise task summary for long-term memory.

## Required Reflection Sections

- Run Summary
- Goal
- Result
- What Worked
- What Failed
- Root Causes
- Confidence Review
- Strategy Improvements
- Future Warnings
- Historical Summary Entry

## Improvement Rule

Only promote an observation into a strategy improvement when it is specific, repeatable, and tied to evidence from the run.

## Historical Summary Requirement

Each reflection entry must include a short narrative summary of the task and the most important observation so future runs can quickly learn from prior outcomes.
