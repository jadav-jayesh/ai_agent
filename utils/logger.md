# Logger

## Purpose

Defines lightweight console logging conventions.

## Suggested levels

- `info`
- `warn`
- `error`
- `success`

## Suggested format

- `[info] message`
- `[warn] message`
- `[error] message`
- `[ok] message`

## Guidance

- keep logs short
- use section markers between agent steps
- avoid verbose provider payload logging by default
